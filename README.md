# monem.fit — Fitness Coaching Platform

Bilingual (Arabic/English) single-page web platform for a fitness coaching business.

**Live site:** https://profound-cranachan-73d35d.netlify.app

## Features
- Full Arabic/English support with RTL
- Thawani payment gateway integration
- Google Sheets data handling via Apps Script
- Email notifications via Formspree

## Tech
HTML • CSS • JavaScript • Google Apps Script • Netlify
